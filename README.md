# Splanner

아이패드 가로 화면용 스터디 플래너입니다.

- 날짜별 공부 목록 · 과목별 타이머 (시작 / 일시정지 / 종료 / 직접 수정)
- 10분 단위 시간표 (타이머 기록 자동 칠하기 + 직접 칠하기)
- 애플펜슬 손글씨 · 그림 (꾹 누르면 직선 · 원 · 타원으로 다듬기, 부분 지우개, 사진 넣기)
- 주간 · 월간 · 연간 통계 (과목별 시간, 시간대별 집중도, 공부 달력)
- 하루 목표 시간, D-Day, 기분 · 날씨, 백업 파일 저장 / 불러오기

## 아이패드에 앱으로 설치

1. 아이패드 **Safari**로 배포 주소를 연다.
2. 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 Splanner 아이콘으로 열면 주소창 없이 전체 화면으로 열린다.

기록은 그 기기의 Safari 안에만 저장된다. 다른 기기로 옮길 때는 설정(☆) → 백업 파일 저장 / 불러오기.

## 앱 아이콘 바꾸기

```powershell
pwsh tools/make-icons.ps1 -Source "내아이콘.png"
```

`assets/icons/`의 아이콘이 모두 새로 만들어진다. 이후 `sw.js`의 `VERSION`을 올리고 배포한다.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `css/style.css` · `css/stats.css` | 플래너 · 통계 디자인 |
| `js/app.js` | 플래너 · 타이머 · 시간표 · 저장 |
| `js/stats.js` | 통계 |
| `js/ink.js` | 도구 막대 · 손글씨 · 사진 |
| `assets/planner.png` | 플래너 디자인 원본 (배경) |
| `manifest.webmanifest` · `sw.js` | 앱 설치 · 오프라인 |
